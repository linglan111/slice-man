# Slice Man v0.1.5

本次更新集中改进章节 AI 处理、字幕自动修复、人名核对及处理过程的可见性。

## 更新内容

- **全文章节切分**：翻译、字幕检查、样式生成及修复文字阶段复用完整章节上下文；短视频同样使用章节，语音识别和全片人名检查除外。容量不足时明确提示，不再隐藏拆分密集章节。
- **服务并发**：文字请求并发上限移至 API 服务设置，默认 2、范围 1–16，同一服务配置的文字操作共享限额。
- **自动循环修复**：每轮重新识别疑点区间、按项目设置翻译，再结合整章上下文审核新旧时间轴和文字，完整成功后保存。复查及结束前一致性补查保持最终评级与保存状态一致，达到轮数上限仍会显示剩余疑点。
- **人名检查**：修复拉丁字母姓名紧邻中日文时被错误拒绝的边界判断；保留全片身份上下文、实际出现位置核对及一次可见纠正。建议仍须确认应用，最近成功批次支持撤销并保护后续人工编辑。
- **并发进度**：阶段、修复轮次、章节/字幕完成数、排队及每个并发请求状态同时可见；合并重复流式入口，保留查看、重开、日志与取消。
- **操作区高度**：切换操作时自动按内容取高，上限为中栏可用高度的 45%；可拖动预览下方分隔线临时调整，下次切换重新适配。其他布局尺寸继续记忆。
- **使用说明**：更新应用内功能导航、README 和英文指南，覆盖当前章节、修复、服务设置与布局操作。

## 安装与使用

下载本 Release 的 Windows x64 安装包，并使用 `SHA256SUMS.txt` 核验。终端用户无需安装 Node.js、Python 或编译器；本地识别引擎、模型和链接工具在应用内按需安装，在线服务使用自己的 API Key。

字幕检查只分析文字与时间，“无疑虑”不保证语音识别正确。自动修复可能在上限处保留疑点；取消或失败保留已完成轮次，未完成轮次不部分替换，重启不会自动继续。原语言项目不调用翻译。

## 验证边界

正式发布流程包含静态检查、单元/集成测试、Electron 回归和打包启动验证，结果以本版本对应的 Actions 记录为准。已有实际服务与原生识别验证仅覆盖记录中的模型、设备和样本，不代表所有服务商、语言或站点兼容；显式未启用的实网/GPU测试不算通过。

安装包未签名。Windows 11 x64 已有验证；Windows 10、干净设备安装及实际升级仍需独立验收。项目使用 MIT；第三方组件保留各自许可证，来源与通知见随包资源。
