# Slice Man v0.1.4

首次 GitHub 开源发布，项目代码使用 MIT License。Windows x64 安装包包含本次最新字幕工作区修改。

## 功能

- 本地 Whisper（可选 NVIDIA 加速）或兼容服务识别；原语言字幕及可选翻译。
- 左侧视频预览、右侧全高字幕校对，下方生成/样式/导出设置可收起。
- 四个分隔线支持鼠标/键盘调整宽高、尺寸记忆及布局重置。
- 字幕增删改、时间定位、实时/双语/全屏预览、选中或时间范围局部修复，以及四级上下文疑虑检查。
- 独立下载/导出设置；SRT、ASS、VTT 字幕文件及烧录字幕的 MP4/MKV 视频。
- 修复预览裁切、表单遮挡、长标题、初始窗口尺寸和动态播放错误布局；应用名称统一为 Slice Man。

## 安装

下载 `Slice-Man-Setup-0.1.4.exe`，使用 `SHA256SUMS.txt` 核验文件。终端用户无需安装 Python、Node.js 或编译器。首次本地识别/链接下载需在应用内安装对应工具及模型；云端服务使用用户自己的 API Key。

安装包未签名。已验证 Windows 11 x64；干净设备安装、实际升级和 Windows 10 仍需独立验收。
